# codex-session-tui

Move, search, and repair Codex sessions from a terminal.

Run it without installing:

```bash
npx -y codex-session-tui@latest
```

Install globally:

```bash
npm i -g codex-session-tui
codex-session-tui
```

The main job is moving Codex sessions between computers, SSH boxes, containers, and renamed folders so `codex resume` can find the conversation again. It also browses sessions, but the important part is search: press `/`, search for the thread you remember, then move/copy/fork it into the place where you need to continue.
